# Лёха Гонщик: Passat B5

Готовая статическая PWA-игра для GitHub Pages.

## GitHub Pages
1. Создай новый публичный репозиторий, например `lekha-racer`.
2. Загрузите содержимое этого архива **в корень репозитория**.
3. Открой **Settings → Pages**.
4. В **Build and deployment** выбери **Deploy from a branch**.
5. Branch: `main`, Folder: `/ (root)` → **Save**.
6. Через 1–3 минуты GitHub покажет ссылку вида `https://username.github.io/lekha-racer/`.

На iPhone: открыть ссылку в Safari → Поделиться → На экран «Домой».

Прогресс хранится локально в браузере (`localStorage`).
